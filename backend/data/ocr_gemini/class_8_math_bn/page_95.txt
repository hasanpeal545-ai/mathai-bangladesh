(গ) (a² − b²)/(a² + ab + b²) ÷ (a + b)/(a³ − b³)
= ((a + b)(a − b))/(a² + ab + b²) × ((a − b)(a² + ab + b²))/(a + b)
= (a − b)(a − b)
∴ নির্ণেয় ভাগফল = (a − b)²

(ঘ) (x³ − 27)/(x² − 7x + 6) ÷ (x² − 9)/(x² − 36)
= (x³ − 3³)/(x² − 6x − x + 6) × (x² − 6²)/(x² − 3²)
= ((x − 3)(x² + 3x + 3²))/((x − 6)(x − 1)) × ((x + 6)(x − 6))/((x + 3)(x − 3))
∴ নির্ণেয় ভাগফল = ((x² + 3x + 9)(x + 6))/((x − 1)(x + 3))

(ঙ) (x³ − y³)/(x³ + y³) ÷ (x² − y²)/(x + y)²
= ((x − y)(x² + xy + y²))/((x + y)(x² − xy + y²)) × (x + y)²/((x + y)(x − y))
∴ নির্ণেয় ভাগফল = (x² + xy + y²)/(x² − xy + y²)
