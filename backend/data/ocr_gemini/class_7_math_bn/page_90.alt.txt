            ২য় রাশি         = x³ + 6x² + 8x
                           = x(x² + 6x + 8)
                           = x(x² + 2x + 4x + 8)
                           = x{x(x + 2) + 4(x + 2)}
                           = x(x + 2)(x + 4)
    ∴ নির্ণেয় গ.সা.গু = x(x + 2)

গ)    ১ম রাশি = x(x+2)(x−5); [খ হতে প্রাপ্ত]

    ৩য় রাশি = x⁴ − 5x³ − 14x²
             = x² (x² − 5x − 14)

             = x² (x + 2)(x − 7)
