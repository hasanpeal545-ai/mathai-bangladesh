উদাহরণ ৮. $x$ এর মান নির্ণয় করো: ক) $\log_{10}x = -2$ খ) $\log_x 324 = 4$

সমাধান:
ক) $\log_{10}x = -2$
বা, $x = 10^{-2} = \frac{1}{10^2} = \frac{1}{100} = 0.01$
$\therefore x = 0.01$

খ) $\log_x 324 = 4$
বা, $x^4 = 324 = 3 \times 3 \times 3 \times 3 \times 2 \times 2 = 3^4 \times 2^2$
বা, $x^4 = 3^4 \times (\sqrt{2})^4$
বা, $x^4 = (3\sqrt{2})^4$
$\therefore x = 3\sqrt{2}$

উদাহরণ ৯. প্রমাণ করো: যে, $3\log_{10}2 + \log_{10}5 = \log_{10}40$

সমাধান: বামপক্ষ $= 3\log_{10}2 + \log_{10}5$
$= \log_{10}2^3 + \log_{10}5$ $[\because \log_a M^r = r\log_a M]$
$= \log_{10}8 + \log_{10}5$
$= \log_{10}(8 \times 5)$ $[\because \log_a (MN) = \log_a M + \log_a N]$
$= \log_{10}40 =$ ডানপক্ষ (প্রমাণিত)
