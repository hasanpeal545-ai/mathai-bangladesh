বা, 240/(x + 1) = (240 − x)/x
বা, 240x = (x + 1)(240 − x)    [আড়গুণন করে]
বা, 240x = 240x + 240 − x² − x
বা, x² + x − 240 = 0 [পক্ষান্তর করে]
বা, x² + 16x − 15x − 240 = 0
বা, x(x + 16) − 15(x + 16) = 0
বা, (x + 16)(x − 15) = 0
∴ x + 16 = 0, অথবা x − 15 = 0
    x + 16 = 0 হলে, x = −16
    x − 15 = 0 হলে, x = 15
কিন্তু কলমের সংখ্যা x ঋণাত্মক হতে পারে না।
∴ x ≠ −16; ∴ x = 15
∴ শাহিক 15টি কলম কিনেছিল।
