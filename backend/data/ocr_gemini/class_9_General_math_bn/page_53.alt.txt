বিকল্প পদ্ধতি:
(a + b + c)² = (a² + b² + c²) + 2(ab + bc + ac)
বা, (15)² = 83 + 2(ab + bc + ac)
বা, 225 − 83 = 2(ab + bc + ac)
বা, 2(ab + bc + ac) = 142
∴ ab + bc + ac = 142/2 = 71

উদাহরণ ১০. a + b + c = 2 এবং ab + bc + ac = 1 হলে, (a + b)² + (b + c)² + (c + a)²
এর মান কত?

সমাধান: (a + b)² + (b + c)² + (c + a)²
= a² + 2ab + b² + b² + 2bc + c² + c² + 2ca + a²
= (a² + b² + c² + 2ab + 2bc + 2ca) + (a² + b² + c²)
= (a + b + c)² + (a + b + c)² − 2(ab + bc + ac)
= (2)² + (2)² − 2 × 1 = 4 + 4 − 2 = 8 − 2 = 6

উদাহরণ ১১. (2x + 3y)(4x − 5y) কে দুইটি বর্গের বিয়োগফলরূপে প্রকাশ করো।

সমাধান: ধরি, 2x + 3y = a এবং 4x − 5y = b
∴ প্রদত্ত রাশি ab = ((a + b)/2)² − ((a − b)/2)²
= ((2x + 3y + 4x − 5y)/2)² − ((2x + 3y − 4x + 5y)/2)² [a ও b এর মান বসিয়ে]
= ((6x − 2y)/2)² − ((8y − 2x)/2)² = {2(3x − y)/2}² − {2(4y − x)/2}²
= (3x − y)² − (4y − x)²
∴ (2x + 3y)(4x − 5y) = (3x − y)² − (4y − x)²

কাজ:
ক) সরল করো: (4x + 3y)² + 2(4x + 3y)(4x − 3y) + (4x − 3y)²
খ) x + y + z = 12 এবং x² + y² + z² = 50 হলে, (x − y)² + (y − z)² + (z − x)²
এর মান নির্ণয় করো।
