উদাহরণ ১৬. যদি a = √3 + √2 হয়, তবে প্রমাণ করো যে, a³ + 1/a³ = 18√3

সমাধান: দেওয়া আছে, a = √3 + √2
∴ 1/a = 1/(√3 + √2)
= (√3 - √2)/((√3 + √2)(√3 - √2)) [লব ও হরকে (√3 - √2) দ্বারা গুণ করে]
= (√3 - √2)/((√3)² - (√2)²) = (√3 - √2)/(3 - 2) = √3 - √2
∴ a + 1/a = (√3 + √2) + (√3 - √2) = √3 + √2 + √3 - √2 = 2√3

এখন, a³ + 1/a³ = (a + 1/a)³ - 3 · a · (1/a)(a + 1/a)
= (2√3)³ - 3(2√3) [∵ a + 1/a = 2√3]
= 2³ · (√3)³ - 3 × 2√3 = 8 · 3√3 - 6√3
= 24√3 - 6√3 = 18√3 (প্রমাণিত)

খ) x³ - y³ - 3(x² + y²) এর মান নির্ণয় করো।
