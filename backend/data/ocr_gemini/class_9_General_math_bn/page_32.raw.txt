অধ্যায় ২. সেট ও ফাংশন
২৭

$B$ অথবা $A$ Union $B$। সেট গঠন পদ্ধতিতে $A \cup B = \{x : x \in A \text{ অথবা } x \in B\}$।
উদাহরণ ৮. $C = \{3, 4, 5\}$ এবং $D = \{4, 6, 8\}$ হলে, $C \cup D$ নির্ণয় করো।

সমাধান: দেওয়া আছে, $C = \{3, 4, 5\}$
এবং $D = \{4, 6, 8\}$
$\therefore C \cup D = \{3, 4, 5\} \cup \{4, 6, 8\} = \{3, 4, 5, 6, 8\}$
নির্ণেয় সেট: $\{3, 4, 5, 6, 8\}$

ছেদ সেট (Intersection of Sets)

দুই বা ততোধিক সেটের সাধারণ উপাদান নিয়ে গঠিত সেটকে ছেদ সেট বলে। মনে করি, $A$ ও $B$
দুটি সেট। $A$ ও $B$ এর ছেদ সেটকে $A \cap B$ দ্বারা প্রকাশ করা হয় এবং পড়া হয় $A$ ছেদ $B$ বা $A$
intersection $B$। সেট গঠন পদ্ধতিতে $A \cap B = \{x : x \in A \text{ এবং } x \in B\}$।

উদাহরণ ৯. $P = \{x \in N : 2 < x \le 6\}$ এবং $Q = \{x \in N : x \text{ জোড় সংখ্যা এবং } x \le 8\}$
হলে, $P \cap Q$ নির্ণয় করো।

সমাধান: দেওয়া আছে,
$P = \{x \in N : 2 < x \le 6\} = \{3, 4, 5, 6\}$
$Q = \{x \in N : x \text{ জোড় সংখ্যা এবং } x \le 8\} = \{2, 4, 6, 8\}$
$\therefore P \cap Q = \{3, 4, 5, 6\} \cap \{2, 4, 6, 8\} = \{4, 6\}$
নির্ণেয় সেট $\{4, 6\}$

নিশ্ছেদ সেট (Disjoint Set)

দুটি সেটের মধ্যে যদি কোনো সাধারণ উপাদান না থাকে তবে সেট দুটিকে পরস্পর নিশ্ছেদ সেট
বলে। মনে করি, $A$ ও $B$ দুটি সেট। $A \cap B = \varnothing$ হলে $A$ ও $B$ পরস্পর নিশ্ছেদ সেট হবে।
যেমন: $A = \{1, 2, 3\}$ ও $B = \{4, 5\}$ সেট দুইটির মধ্যে কোনো সাধারণ উপাদান নেই। তাহলে
$A$ ও $B$ পরস্পর নিশ্ছেদ সেট।

কাজ: $U = \{1, 3, 5, 9, 7, 11\}$, $E = \{1, 5, 9\}$ এবং $F = \{3, 7, 11\}$ হলে, $E^c \cup F^c$
এবং $E^c \cap F^c$ নির্ণয় করো।
