উদাহরণ ৬. x - y = 2 এবং xy = 24 হলে, x + y এর মান কত?

সমাধান: (x + y)² = (x - y)² + 4xy = (2)² + 4 × 24 = 4 + 96 = 100
∴ x + y = ±√(100) = ± 10

উদাহরণ ৭. যদি a⁴ + a²b² + b⁴ = 3 এবং a² + ab + b² = 3 হয়, তবে a² + b² এর মান কত?

সমাধান: a⁴ + a²b² + b⁴
= (a²)² + 2a²b² + (b²)² - a²b²
= (a² + b²)² - (ab)²
= (a² + b² + ab)(a² + b² - ab)
= (a² + ab + b²)(a² - ab + b²)
∴ 3 = 3(a² - ab + b²) [মান বসিয়ে]
বা, a² - ab + b² = 3/3 = 1
এখন, a² + ab + b² = 3 এবং a² - ab + b² = 1
যোগ করে পাই, 2(a² + b²) = 4
বা, a² + b² = 4/2 = 2
∴ a² + b² = 2

উদাহরণ ৮. প্রমাণ করো যে, (a + b)⁴ - (a - b)⁴ = 8ab(a² + b²)

সমাধান: (a + b)⁴ - (a - b)⁴
= {(a + b)²}² - {(a - b)²}²
= {(a + b)² + (a - b)²}{(a + b)² - (a - b)²}
= 2(a² + b²) × 4ab [অনুসিদ্ধান্ত ৫ এবং অনুসিদ্ধান্ত ৬ ব্যবহার করে]
= 8ab(a² + b²)
∴ (a + b)⁴ - (a - b)⁴ = 8ab(a² + b²)

উদাহরণ ৯. a + b + c = 15 এবং a² + b² + c² = 83 হলে, ab + bc + ac এর মান কত?

সমাধান: প্রথম পদ্ধতি:
2(ab + bc + ac) = (a + b + c)² - (a² + b² + c²) = (15)² - 83 = 225 - 83 = 142
∴ ab + bc + ac = 142/2 = 71
