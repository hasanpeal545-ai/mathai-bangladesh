উদাহরণ ২৩. f(y) = (y³ - 3y² + 1)/(y(1 - y)) হলে দেখাও যে f(1/y) = f(1 - y)

সমাধান: f(y) = (y³ - 3y² + 1)/(y(1 - y))

∴ f(1/y) = ((1/y)³ - 3(1/y)² + 1)/((1/y)(1 - 1/y)) = ((1 - 3y + y³)/y³)/((y - 1)/y²)

= (1 - 3y + y³)/y³ × y²/(y - 1) = (1 - 3y + y³)/(y(y - 1))

আবার, f(1 - y) = ((1 - y)³ - 3(1 - y)² + 1)/((1 - y)(1 - (1 - y)))

= (1 - 3y + 3y² - y³ - 3(1 - 2y + y²) + 1)/((1 - y)(1 - 1 + y))

= (1 - 3y + 3y² - y³ - 3 + 6y - 3y² + 1)/(y(1 - y))

= (-1 + 3y - y³)/(y(1 - y)) = (-(1 - 3y + y³))/(-y(y - 1))

= (1 - 3y + y³)/(y(y - 1))

∴ f(1/y) = f(1 - y) দেখানো হলো।
