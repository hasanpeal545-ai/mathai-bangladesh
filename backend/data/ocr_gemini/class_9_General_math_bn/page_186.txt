অধ্যায় ৯. ত্রিকোণমিতিক অনুপাত
১৮১

= (\sin²\theta + \cos²\theta)/(\sin\theta · \cos\theta)
= 1/(\sin\theta · \cos\theta) [∵ \sin²\theta + \cos²\theta = 1]
= 1/(\sin\theta) · 1/(\cos\theta)
= cosec\theta · \sec\theta
= \sec\theta · cosec\theta = ডানপক্ষ (প্রমাণিত)

উদাহরণ ৬. প্রমাণ করো যে, sec²\theta + cosec²\theta = \sec²\theta · cosec²\theta

সমাধান:
বামপক্ষ = sec²\theta + cosec²\theta
= 1/(\cos²\theta) + 1/(\sin²\theta)
= (\sin²\theta + \cos²\theta)/(\cos²\theta · \sin²\theta)
= 1/(\cos²\theta · \sin²\theta)
= 1/(\cos²\theta) · 1/(\sin²\theta)
= \sec²\theta · cosec²\theta
= ডানপক্ষ (প্রমাণিত)

উদাহরণ ৭. প্রমাণ করো যে, 1/(1 + \sin²\theta) + 1/(1 + cosec²\theta) = 1

সমাধান:
বামপক্ষ = 1/(1 + \sin²\theta) + 1/(1 + cosec²\theta)
= 1/(1 + \sin²\theta) + 1/(1 + 1/(\sin²\theta))
= 1/(1 + \sin²\theta) + (\sin²\theta)/(1 + \sin²\theta)
= (1 + \sin²\theta)/(1 + \sin²\theta)
= 1 = ডানপক্ষ (প্রমাণিত)
