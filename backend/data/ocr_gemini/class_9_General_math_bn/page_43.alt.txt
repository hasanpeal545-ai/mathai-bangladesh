গণিত
উদাহরণ ২৪. সার্বিক সেট U = {x : x ∈ N এবং x ≤ 6}, A = {x : x মৌলিক সংখ্যা এবং
x ≤ 5}, B = {x : x জোড় সংখ্যা এবং x ≤ 6} এবং C = A \ B
ক) A^{c} নির্ণয় করো।
খ) দেখাও যে, A ∪ B = (A \ B) ∪ (B \ A) ∪ (A ∩ B)
গ) দেখাও যে, (A ∩ C) × B = (A × B) ∩ (C × B)

সমাধান:
ক) দেওয়া আছে, U = {x : x ∈ N এবং x ≤ 6} = {1, 2, 3, 4, 5, 6}
A = {x : x মৌলিক সংখ্যা এবং x ≤ 5} = {2, 3, 5}
∴ A^{c} = U \ A = {1, 2, 3, 4, 5, 6} - {2, 3, 5} = {1, 4, 6}
খ) দেওয়া আছে,
B = {x : x জোড় সংখ্যা এবং x ≤ 6} = {2, 4, 6}
∴ A ∪ B = {2, 3, 5} ∪ {2, 4, 6} = {2, 3, 4, 5, 6} ... ... (1)
A \ B = {2, 3, 5} - {2, 4, 6} = {3, 5}
B \ A = {2, 4, 6} - {2, 3, 5} = {4, 6}
A ∩ B = {2, 3, 5} ∩ {2, 4, 6} = {2}
∴ (A \ B) ∪ (B \ A) ∪ (A ∩ B) = {3, 5} ∪ {4, 6} ∪ {2} = {2, 3, 4, 5, 6} ... ... (2)
সুতরাং (1) ও (2) তুলনা করে পাই,
A ∪ B = (A \ B) ∪ (B \ A) ∪ (A ∩ B)
গ) ‘খ’ হতে পাই,
C = A \ B = {3, 5}
A ∩ C = {2, 3, 5} ∩ {3, 5} = {3, 5}
∴ (A ∩ C) × B = {3, 5} × {2, 4, 6}
= {(3, 2), (3, 4), (3, 6), (5, 2), (5, 4), (5, 6)} ... ... (3)
A × B = {2, 3, 5} × {2, 4, 6}
= {(2, 2), (2, 4), (2, 6), (3, 2), (3, 4), (3, 6), (5, 2), (5, 4), (5, 6)}
C × B = {3, 5} × {2, 4, 6}
= {(3, 2), (3, 4), (3, 6), (5, 2), (5, 4), (5, 6)}
∴ (A × B) ∩ (C × B)
