অধ্যায় ২. সেট ও ফাংশন
২৭

B অথবা A Union B। সেট গঠন পদ্ধতিতে A ∪ B = {x : x ∈ A  অথবা  x ∈ B}।
উদাহরণ ৮. C = {3, 4, 5} এবং D = {4, 6, 8} হলে, C ∪ D নির্ণয় করো।

সমাধান: দেওয়া আছে, C = {3, 4, 5}
এবং D = {4, 6, 8}
∴ C ∪ D = {3, 4, 5} ∪ {4, 6, 8} = {3, 4, 5, 6, 8}
নির্ণেয় সেট: {3, 4, 5, 6, 8}

ছেদ সেট (Intersection of Sets)

দুই বা ততোধিক সেটের সাধারণ উপাদান নিয়ে গঠিত সেটকে ছেদ সেট বলে। মনে করি, A ও B
দুইটি সেট। A ও B এর ছেদ সেটকে A ∩ B দ্বারা প্রকাশ করা হয় এবং পড়া হয় A ছেদ B বা A
intersection B। সেট গঠন পদ্ধতিতে A ∩ B = {x : x ∈ A  এবং  x ∈ B}।

উদাহরণ ৯. P = {x ∈ N : 2 < x ≤ 6} এবং Q = {x ∈ N : x  জোড় সংখ্যা এবং  x ≤ 8}
হলে, P ∩ Q নির্ণয় করো।

সমাধান: দেওয়া আছে,
P = {x ∈ N : 2 < x ≤ 6} = {3, 4, 5, 6}
Q = {x ∈ N : x  জোড় সংখ্যা এবং  x ≤ 8} = {2, 4, 6, 8}
∴ P ∩ Q = {3, 4, 5, 6} ∩ {2, 4, 6, 8} = {4, 6}
নির্ণেয় সেট {4, 6}

নিশ্ছেদ সেট (Disjoint Set)

দুইটি সেটের মধ্যে যদি কোনো সাধারণ উপাদান না থাকে তবে সেট দুইটিকে পরস্পর নিশ্ছেদ সেট
বলে। মনে করি, A ও B দুইটি সেট। A ∩ B = ∅ হলে A ও B পরস্পর নিশ্ছেদ সেট হবে।
যেমন: A = {1, 2, 3} ও B = {4, 5} সেট দুইটির মধ্যে কোনো সাধারণ উপাদান নেই। তাহলে
A ও B পরস্পর নিশ্ছেদ সেট।

কাজ: U = {1, 3, 5, 9, 7, 11}, E = {1, 5, 9} এবং F = {3, 7, 11} হলে, E^c ∪ F^c
এবং E^c ∩ F^c নির্ণয় করো।
