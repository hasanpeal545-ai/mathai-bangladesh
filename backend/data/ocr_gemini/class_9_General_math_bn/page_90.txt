উদাহরণ ৮. x এর মান নির্ণয় করো: ক) log₁₀x = −2 খ) logₓ324 = 4

সমাধান:
ক) log₁₀x = −2
বা, x = 10⁻² = 1/10² = 1/100 = 0.01
∴ x = 0.01

খ) logₓ324 = 4
বা, x⁴ = 324 = 3 × 3 × 3 × 3 × 2 × 2 = 3⁴ × 2²
বা, x⁴ = 3⁴ × (√2)⁴
বা, x⁴ = (3√2)⁴
∴ x = 3√2

উদাহরণ ৯. প্রমাণ করো যে, 3log₁₀2 + log₁₀5 = log₁₀40

সমাধান: বামপক্ষ = 3log₁₀2 + log₁₀5
= log₁₀2³ + log₁₀5 [∵ logₐMʳ = rlogₐM]
= log₁₀8 + log₁₀5
= log₁₀(8 × 5) [∵ logₐ(MN) = logₐM + logₐN]
= log₁₀40 = ডানপক্ষ (প্রমাণিত)
