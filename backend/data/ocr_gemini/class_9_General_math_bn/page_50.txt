অনুসিদ্ধান্ত ৬. ab = ((a+b)/2)² - ((a-b)/2)²

প্রমাণ: সূত্র ১ ও সূত্র ২ হতে,
a² + 2ab + b² = (a+b)²
a² - 2ab + b² = (a-b)²
_________________________________________
বিয়োগ করে, 4ab = (a+b)² - (a-b)²
বা, ab = ((a+b)²)/4 - ((a-b)²)/4
সুতরাং, ab = ((a+b)/2)² - ((a-b)/2)²

মন্তব্য : অনুসিদ্ধান্ত ৬ প্রয়োগ করে যেকোনো দুইটি রাশির গুণফলকে ঐ দুইটি রাশির সমষ্টির অর্ধেকের বর্গ হতে ঐ দুইটি রাশির অন্তরের অর্ধেকের বর্গের অন্তররূপে প্রকাশ করা যায়।

সূত্র ৩. a² - b² = (a+b)(a-b)

অর্থাৎ, দুইটি রাশির বর্গের বিয়োগফল = রাশি দুইটির যোগফল × রাশি দুইটির বিয়োগফল

সূত্র ৪. (x+a)(x+b) = x² + (a+b)x + ab

অর্থাৎ, (x+a)(x+b) = x² + (a ও b এর বীজগাণিতিক যোগফল)x + (a ও b এর গুণফল)

বর্গসূত্রের সম্প্রসারণ: a+b+c রাশিটিতে তিনটি পদ আছে। একে (a+b) এবং c এ দুইটি পদের সমষ্টিরূপে বিবেচনা করা যায়। অতএব, সূত্র ১ প্রয়োগ করে রাশিটির বর্গ করে পাই,

(a+b+c)² = {(a+b)+c}² = (a+b)² + 2(a+b)c + c²
       = a² + 2ab + b² + 2ac + 2bc + c² = a² + b² + c² + 2ab + 2bc + 2ac

সূত্র ৫. (a+b+c)² = a² + b² + c² + 2ab + 2bc + 2ac

অনুসিদ্ধান্ত ৭. a² + b² + c² = (a+b+c)² - 2(ab+bc+ac)

অনুসিদ্ধান্ত ৮. 2(ab+bc+ac) = (a+b+c)² - (a²+b²+c²)

দ্রষ্টব্য: সূত্র ৫ প্রয়োগ করে পাই,

ক) (a+b-c)² = {a+b+(-c)}²
   = a² + b² + (-c)² + 2ab + 2b(-c) + 2a(-c)
   = a² + b² + c² + 2ab - 2bc - 2ac

খ) (a-b+c)² = {a+(-b)+c}²
   = a² + (-b)² + c² + 2a(-b) + 2(-b)c + 2ac
   = a² + b² + c² - 2ab - 2bc + 2ac
