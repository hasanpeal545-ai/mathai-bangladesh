অধ্যায় ৩. বীজগাণিতিক রাশি
৫৭
সমাধান: 8x³ + 36x²y + 54xy² + 27y³
= (2x)³ + 3 × (2x)² × 3y + 3 × 2x × (3y)² + (3y)³
= (2x + 3y)³ = (2x + 3y)(2x + 3y)(2x + 3y)
দুইটি ঘন এর যোগফল বা বিয়োগফলের সূত্র দিয়ে: a³ + b³ = (a + b)(a² − ab + b²) এবং
a³ − b³ = (a − b)(a² + ab + b²) সূত্র দুইটি ব্যবহার করে উৎপাদক নির্ণয় করা যায়।
উদাহরণ ২৮. উৎপাদকে বিশ্লেষণ করো: ক) 8a³ + 27b³ খ) a⁶ − 64

সমাধান:
ক) 8a³ + 27b³ = (2a)³ + (3b)³
= (2a + 3b){(2a)² − 2a × 3b + (3b)²}
= (2a + 3b)(4a² − 6ab + 9b²)
খ) a⁶ − 64 = (a²)³ − (4)³ = (a² − 4){(a²)² + a² × 4 + (4)²}
= (a² − 4)(a⁴ + 4a² + 16)
কিন্তু a² − 4 = a² − 2² = (a + 2)(a − 2)
এবং a⁴ + 4a² + 16 = (a²)² + (4)² + 4a²
= (a² + 4)² − 2(a²)(4) + 4a²
= (a² + 4)² − 4a²
= (a² + 4)² − (2a)²
= (a² + 4 + 2a)(a² + 4 − 2a)
= (a² + 2a + 4)(a² − 2a + 4)
∴ a⁶ − 64 = (a + 2)(a − 2)(a² + 2a + 4)(a² − 2a + 4)
বিকল্প নিয়ম: a⁶ − 64 = (a³)² − 8²
= (a³ + 8)(a³ − 8)
= (a³ + 2³)(a³ − 2³)
= (a + 2)(a² − 2a + 4)(a − 2)(a² + 2a + 4)
= (a + 2)(a − 2)(a² + 2a + 4)(a² − 2a + 4)
