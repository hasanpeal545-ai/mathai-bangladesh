সমাধান: মনে করি, সমিতির সদস্য সংখ্যা x এবং জনপ্রতি দেয় চাঁদার পরিমাণ q টাকা। তাহলে,
মোট চাঁদা, A = qx = 45,000 টাকা।
প্রকৃতপক্ষে চাঁদা প্রদানকারী সদস্য সংখ্যা ছিল (x − 5) জন এবং জনপ্রতি চাঁদা (q + 15) টাকা।
তাহলে, মোট চাঁদা হলো (x − 5)(q + 15)
প্রশ্নানুসারে,
qx = (x − 5)(q + 15) ······ (1)
qx = 45000 ······ (2)
সমীকরণ (1) থেকে পাই,
qx = (x − 5)(q + 15)
বা, qx = qx − 5q + 15x − 75
বা, 5q = 15x − 75 = 5(3x − 15)
∴ q = 3x − 15
সমীকরণ (2) এ q এর মান বসিয়ে পাই,
(3x − 15) × x = 45000
বা, 3x² − 15x = 45000
বা, x² − 5x = 15000 [উভয়পক্ষকে 3 দ্বারা ভাগ করে]
বা, x² − 5x − 15000 = 0
বা, x² − 125x + 120x − 15000 = 0
বা, x(x − 125) + 120(x − 125) = 0
বা, (x − 125)(x + 120) = 0
সুতরাং, (x − 125) = 0 অথবা (x + 120) = 0
বা, x = 125 বা, x = −120

যেহেতু সদস্য সংখ্যা ঋণাত্মক হতে পারে না, তাই x এর মান −120 গ্রহণযোগ্য নয়।
সুতরাং, সমিতির সদস্য সংখ্যা 125
