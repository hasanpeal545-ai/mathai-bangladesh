অধ্যায় ৫. এক চলকবিশিষ্ট সমীকরণ

নতুন ছাত্রের নম্বরসহ (x + 1) জন ছাত্রের প্রাপ্ত নম্বরের গড় = (1950 + 34)/(x + 1) = 1984/(x + 1)
খ) প্রশ্নমতে, 1950/x = 1984/(x + 1) + 1
বা, 1950/x − 1984/(x + 1) = 1 [পক্ষান্তর করে]
বা, (1950x + 1950 − 1984x)/(x(x + 1)) = 1
বা, x² + x = 1950x − 1984x + 1950 [আড়গুণন করে]
বা, x² + x = 1950 − 34x
∴ x² + 35x − 1950 = 0 [দেখানো হলো]
গ) x² + 35x − 1950 = 0
বা, x² + 65x − 30x − 1950 = 0
বা, x(x + 65) − 30(x + 65) = 0
বা, (x + 65)(x − 30) = 0
∴ x + 65 = 0 অথবা x − 30 = 0
x + 65 = 0 হলে, x = −65
আবার, x − 30 = 0 হলে, x = 30
যেহেতু ছাত্রের সংখ্যা x ঋণাত্মক হতে পারে না,
সুতরাং, x ≠ −65
∴ x = 30
∴ প্রথম ক্ষেত্রে গড় = 1950/30 = 65 এবং দ্বিতীয় ক্ষেত্রে গড় = 1984/31 = 64
