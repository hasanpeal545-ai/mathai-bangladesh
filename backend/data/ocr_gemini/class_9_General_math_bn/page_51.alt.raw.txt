উদাহরণ ৪. a + b + c + d এর বর্গ কত?

সমাধান: (a + b + c + d)² = {(a + b) + (c + d)}²
= (a + b)² + 2(a + b)(c + d) + (c + d)²
= a² + 2ab + b² + 2(ac + ad + bc + bd) + c² + 2cd + d²
= a² + b² + c² + d² + 2ab + 2ac + 2ad + 2bc + 2bd + 2cd
