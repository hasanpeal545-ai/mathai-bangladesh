অধ্যায় ৫. এক চলকবিশিষ্ট সমীকরণ
১০৩

আবার, x − 1 = 0 হলে, x = 1
∴ সমাধান সেট {1, 4}

উদাহরণ ১১. সমাধান করো: ( (x + a)/(x − a) )² − 5( (x + a)/(x − a) ) + 6 = 0

সমাধান: ( (x + a)/(x − a) )² − 5( (x + a)/(x − a) ) + 6 = 0 ...(1)

ধরি, (x + a)/(x − a) = y

∴ (1) হতে পাই, y² − 5y + 6 = 0

বা, y² − 2y − 3y + 6 = 0

বা, y(y − 2) − 3(y − 2) = 0

বা, (y − 2)(y − 3) = 0

∴ y − 2 = 0 হলে, y = 2

অথবা y − 3 = 0 হলে, y = 3

এখন, y = 2 হলে,

(x + a)/(x − a) = 2/1 [ y এর মান বসিয়ে]

বা, x + a = 2(x − a) [আড়গুণন করে]

বা, x + a = 2x − 2a

বা, 2x − x = a + 2a

বা, x = 3a

আবার, y = 3 হলে,

(x + a)/(x − a) = 3/1

বা, x + a = 3(x − a) [আড়গুণন করে]

বা, x + a = 3x − 3a

বা, 3x − x = a + 3a

বা, x = 2a

∴ সমাধান x = 2a অথবা, x = 3a
