উদাহরণ ১৫. 0.2̇ কে 42.1̇8̇ দ্বারা গুণ কর।

সমাধান:
$0.2\dot{8} = \frac{28 - 2}{90} = \frac{26}{90} = \frac{13}{45}$
$42.1\dot{8} = \frac{4218 - 42}{99} = \frac{4176}{99} = \frac{464}{11}$

$\therefore 0.2\dot{8} \times 42.1\dot{8} = \frac{13}{45} \times \frac{464}{11} = \frac{6032}{495} = 12.1\dot{8}\dot{5}$

নির্ণেয় গুণফল $12.1\dot{8}\dot{5}$

উদাহরণ ১৬. $2.5 \times 4.3\dot{5} \times 1.2\dot{3}\dot{4}$ কত?

সমাধান:
$2.5 = \frac{25}{10} = \frac{5}{2}$
$4.3\dot{5} = \frac{435 - 43}{90} = \frac{392}{90}$
$1.2\dot{3}\dot{4} = \frac{1234 - 12}{990} = \frac{1222}{990} = \frac{611}{495}$

$\therefore 2.5 \times 4.3\dot{5} \times 1.2\dot{3}\dot{4} = \frac{5}{2} \times \frac{392}{90} \times \frac{611}{495} = \frac{119756}{8910} = 13.440628 \dots$

নির্ণেয় গুণফল $13.440628$ (প্রায়)

উদাহরণ ১৭. $7.3\dot{2}$ কে $0.2\dot{7}$ দ্বারা ভাগ কর।

সমাধান:
$7.3\dot{2} = \frac{732 - 7}{99} = \frac{725}{99}$
$0.2\dot{7} = \frac{27 - 2}{90} = \frac{25}{90} = \frac{5}{18}$

$\therefore 7.3\dot{2} \div 0.2\dot{7} = \frac{725}{99} \div \frac{5}{18} = \frac{725}{99} \times \frac{18}{5} = \frac{290}{11} = 26.\dot{3}\dot{6}$

নির্ণেয় ভাগফল $26.\dot{3}\dot{6}$
