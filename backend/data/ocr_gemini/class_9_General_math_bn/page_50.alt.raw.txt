অধ্যায় ৩. বীজগণিতিক রাশি
৪৫

অনুসিদ্ধান্ত ৬. $ab = \left(\frac{a + b}{2}\right)^2 - \left(\frac{a - b}{2}\right)^2$

প্রমাণ: সূত্র ১ ও সূত্র ২ হতে,
  $a^2 + 2ab + b^2 = (a + b)^2$
  $a^2 - 2ab + b^2 = (a - b)^2$
────────────────────────────────────
বিয়োগ করে, $4ab = (a + b)^2 - (a - b)^2$
বা, $ab = \frac{(a + b)^2}{4} - \frac{(a - b)^2}{4}$
সুতরাং, $ab = \left(\frac{a + b}{2}\right)^2 - \left(\frac{a - b}{2}\right)^2$

মন্তব্য: অনুসিদ্ধান্ত ৬ প্রয়োগ করে যেকোনো দুটি রাশির গুণফলকে ঐ দুইটি রাশির সমষ্টির অর্ধেকের বর্গ হতে ঐ দুইটি রাশির অন্তরের অর্ধেকের বর্গের অন্তররূপে প্রকাশ করা যায়।

সূত্র ৩. $a^2 - b^2 = (a + b)(a - b)$

অর্থাৎ, দুটি রাশি বর্গের বিয়োগফল = রাশি দুইটির যোগফল $\times$ রাশি দুইটির বিয়োগফল

সূত্র ৪. $(x + a)(x + b) = x^2 + (a + b)x + ab$

অর্থাৎ, $(x + a)(x + b) = x^2 + (a\text{ ও }b\text{ এর বীজগণিতিক যোগফল })\text{ }x + (a\text{ ও }b\text{ এর গুণফল })$

বর্গসূত্রের সম্প্রসারণ: $a + b + c$ রাশিটিতে তিনটি পদ আছে। একে $(a + b)$ এবং $c$ এ দুইটি পদের সমষ্টিরূপে বিবেচনা করা যায়। অতএব, সূত্র ১ প্রয়োগ করে রাশিটির বর্গ করে পাই,

$(a + b + c)^2 = \{(a + b) + c\}^2 = (a + b)^2 + 2(a + b)c + c^2$
$= a^2 + 2ab + b^2 + 2ac + 2bc + c^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ac$

সূত্র ৫. $(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ac$

অনুসিদ্ধান্ত ৭. $a^2 + b^2 + c^2 = (a + b + c)^2 - 2(ab + bc + ac)$

অনুসিদ্ধান্ত ৮. $2(ab + bc + ac) = (a + b + c)^2 - (a^2 + b^2 + c^2)$

দ্রষ্টব্য: সূত্র ৫ প্রয়োগ করে পাই,

ক) $(a + b - c)^2 = \{a + b + (-c)\}^2$
$= a^2 + b^2 + (-c)^2 + 2ab + 2b(-c) + 2a(-c)$
$= a^2 + b^2 + c^2 + 2ab - 2bc - 2ac$

খ) $(a - b + c)^2 = \{a + (-b) + c\}^2$
$= a^2 + (-b)^2 + c^2 + 2a(-b) + 2(-b)c + 2ac$
$= a^2 + b^2 + c^2 - 2ab - 2bc + 2ac$
