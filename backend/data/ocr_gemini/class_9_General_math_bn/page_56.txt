প্রমাণ: a³ - b³ = (a - b)³ + 3ab(a - b)
= (a - b){(a - b)² + 3ab}
= (a - b)(a² - 2ab + b² + 3ab)
= (a - b)(a² + ab + b²)

উদাহরণ ১২. 2x + 3y এর ঘন নির্ণয় করো।

সমাধান: (2x + 3y)³
= (2x)³ + 3 · (2x)² · 3y + 3 · 2x · (3y)² + (3y)³
= 8x³ + 3 · 4x² · 3y + 3 · 2x · 9y² + 27y³
= 8x³ + 36x²y + 54xy² + 27y³

উদাহরণ ১৩. 2x - y এর ঘন নির্ণয় করো।

সমাধান: (2x - y)³
= (2x)³ - 3(2x)² · y + 3 · 2x · y² - y³
= 8x³ - 3 · 4x² · y + 3 · 2x · y² - y³
= 8x³ - 12x²y + 6xy² - y³

উদাহরণ ১৪. x = 37 হলে, 8x³ + 72x² + 216x + 216 এর মান কত?

সমাধান: 8x³ + 72x² + 216x + 216
= (2x)³ + 3 · (2x)² · 6 + 3 · 2x · (6)² + (6)³
= (2x + 6)³ = (2 × 37 + 6)³ [মান বসিয়ে]
= (74 + 6)³ = (80)³ = 512000

উদাহরণ ১৫. যদি x - y = 8 এবং xy = 5 হয়, তবে x³ - y³ + 8(x + y)² এর মান কত?

সমাধান: x³ - y³ + 8(x + y)²
= (x - y)³ + 3xy(x - y) + 8{(x - y)² + 4xy}
= (8)³ + 3 × 5 × 8 + 8(8² + 4 × 5) [মান বসিয়ে]
= 8³ + 15 × 8 + 8(8² + 4 × 5)
