অনুশীলনী ২.১

১. নিচের সেটগুলোকে তালিকা পদ্ধতিতে প্রকাশ করো:
ক) {x ∈ N : x² > 9  এবং  x³ < 130}
খ) {x ∈ Z : x² > 5  এবং  x³ ≤ 36}
গ) {x ∈ N : x, 36  এর গুণনীয়ক এবং  6  এর গুণিতক }
ঘ) {x ∈ N : x³ > 25  এবং  x⁴ < 264}

২. নিচের সেটগুলোকে সেট গঠন পদ্ধতিতে প্রকাশ করো:
ক) {3, 5, 7, 9, 11}
খ) {1, 2, 3, 4, 6, 9, 12, 18, 36}
গ) {4, 8, 12, 16, 20, 24, 28, 32, 36, 40}
ঘ) {± 4, ± 5, ± 6}

৩. A = {2, 3, 4} এবং B = {1, 2, a} এবং C = {2, a, b} হলে, নিচের সেটগুলো নির্ণয় করো:
ক) B \ C
খ) A ∪ B
গ) A ∩ C
ঘ) A ∪ (B ∩ C)
ঙ) A ∩ (B ∪ C)

৪. U = {1, 2, 3, 4, 5, 6, 7}, A = {1, 3, 5}, B = {2, 4, 6} এবং C = {3, 4, 5, 6, 7}
হলে, নিম্নলিখিত ক্ষেত্রে সত্যতা যাচাই করো:
ক) (A ∪ B)' = A' ∩ B'
খ) (B ∩ C)' = B' ∪ C'
গ) (A ∪ B) ∩ C = (A ∩ C) ∪ (B ∩ C)
ঘ) (A ∩ B) ∪ C = (A ∪ C) ∩ (B ∪ C)

৫. Q = {x, y} এবং R = {m, n, l} হলে, P(Q) এবং P(R) নির্ণয় করো।

৬. A = {a, b}, B = {a, b, c} এবং C = A ∪ B হলে, দেখাও যে, P(C) এর উপাদান সংখ্যা
2ⁿ, যেখানে n হচ্ছে C এর উপাদান সংখ্যা।

৭. ক) (x - 1, y + 2) = (y - 2, 2x + 1) হলে, x এবং y এর মান নির্ণয় করো।
খ) (ax - cy, a² - c²) = (0, ay - cx) হলে, (x, y) এর মান নির্ণয় করো।
গ) (6x - y, 13) = (1, 3x + 2y) হলে, (x, y) নির্ণয় করো।
