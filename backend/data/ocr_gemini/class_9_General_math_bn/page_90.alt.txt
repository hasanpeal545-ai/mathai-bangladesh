উদাহরণ ৮. x এর মান নির্ণয় করো: ক) \log_{10}x = -2 খ) \log_x 324 = 4

সমাধান:
ক) \log_{10}x = -2
বা, x = 10^{-2} = 1/(10²) = 1/100 = 0.01
∴ x = 0.01

খ) \log_x 324 = 4
বা, x⁴ = 324 = 3 × 3 × 3 × 3 × 2 × 2 = 3⁴ × 2²
বা, x⁴ = 3⁴ × (√2)⁴
বা, x⁴ = (3√2)⁴
∴ x = 3√2

উদাহরণ ৯. প্রমাণ করো: যে, 3\log_{10}2 + \log_{10}5 = \log_{10}40

সমাধান: বামপক্ষ = 3\log_{10}2 + \log_{10}5
= \log_{10}2³ + \log_{10}5 [∵ \log_a M^r = r\log_a M]
= \log_{10}8 + \log_{10}5
= \log_{10}(8 × 5) [∵ \log_a (MN) = \log_a M + \log_a N]
= \log_{10}40 = ডানপক্ষ (প্রমাণিত)
