# BanglaMathai

A RAG-based Adaptive Bangla Math Tutoring System for NCTB Class 6-10 students in Bangladesh.

## Problem

Millions of underprivileged children in Bangladesh cannot afford a private math tutor or guide books. BanglaMathai gives them a free AI math tutor that follows the exact NCTB curriculum and SSC board answer format.

## Tech Stack

- **Backend:** Python, FastAPI, LangChain, LangGraph, Qdrant Cloud, Groq, Google Gemini, Celery
- **Frontend:** React, TypeScript, TailwindCSS, PWA, Plotly.js
- **Infra:** Docker, Docker Compose, Nginx, PostgreSQL, Redis
