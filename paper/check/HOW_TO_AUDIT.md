# তপিয়াল এর যাচাই (Human audit) — কীভাবে করবে

উদ্দেশ্য: Claude (chat) যা যাচাই করেছে, তার কতটা ভুল বাদ পড়েছে তা একজন গণিত শিক্ষক হিসেবে মাপা।

১. `paper/check/HUMAN_AUDIT.csv` Excel এ খোলো (ডাবল ক্লিক)।
২. প্রতিটা সারির জন্য:
   - বাম পাশে ছবি খোলো: `paper/check/audit_images/page_N.png`
   - ডান পাশে text খোলো: `backend/data/ocr_gemini/class_9_General_math_bn/page_N.txt`
     (VS Code এ: ছবির tab এর উপর right click → "Split Right", তারপর text ফাইল খোলো)
   - লাইন ধরে মেলাও। বিশেষ করে দেখবে: সংখ্যা, ঘাত, ভগ্নাংশ, বন্ধনী, আবৃত্ত দশমিকের ফোঁটা, প্রশ্ন নম্বর।
৩. সব ঠিক হলে `result` কলামে লেখো: ঠিক
   ভুল পেলে লেখো: ভুল, আর পরের কলামে লাইন + সঠিকটা, যেমন: "লাইন 12: 3/7 হবে 3/8"
৪. text ফাইল নিজে বদলাবে না — শুধু CSV তে লিখবে। আমি পরে ঠিক করব।
৫. ছবিতে থাকা চিত্র/গ্রাফ/ভেনচিত্র text এ না থাকলে সেটা ভুল ধরবে না (জানা সীমাবদ্ধতা)।
৬. "must-check" সারিগুলো (২৪, ৮৫, ৮৬) আগে করো — এগুলো অনুশীলনী, আমি পুরো নতুন করে লিখেছি।

শেষ হলে Claude (chat) কে বলো "audit done"।
